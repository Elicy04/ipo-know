## 对话附件功能前置配置

知识问答支持在对话时上传临时文件作为额外上下文（最多 10 个文件）。

### 前置条件

需在百炼控制台开启"文件预解析"功能：

1. 登录 [百炼控制台](https://bailian.console.aliyun.com)
2. 进入"知识问答服务"页面
3. 在对应服务的设置中开启"文件预解析"选项

> ⚠️ 未开启此选项时，上传的附件不会参与问答推理。

### 支持的文件格式

| 类型 | 格式 |
|------|------|
| 文档 | .txt, .pdf, .doc, .docx, .md, .pptx, .ppt, .xls, .xlsx |
| 图片 | .png, .jpg, .jpeg, .bmp, .gif |

### 限制

- 单次对话最多上传 10 个文件
- 单文件大小上限 100MB
- 文件仅在当前对话中生效，清空对话或切换平台后自动清理
